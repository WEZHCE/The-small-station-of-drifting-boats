## 二、核心模型

### 2.1 坐标系

- 所有坐标 ×2 取整。
- 3×3：坐标 ∈ {-2, 0, 2}，maxc = 2
- 4×4：坐标 ∈ {-3, -1, 1, 3}，maxc = 3
- 面法线：U=[0,1,0], D=[0,-1,0], R=[1,0,0], L=[-1,0,0], F=[0,0,1], B=[0,0,-1]

### 2.2 块（Piece）

```js
{ p: [x,y,z],           // 当前位置（世界坐标，×2 整数）
  m: [[...3x3]],        // 当前旋转矩阵（整数）
  st: [{n:[x,y,z], c}]  // 贴纸列表：n=局部法线, c=颜色索引
}
```

- 只创建 st.length > 0 的块（跳过内部不可见块）。
- 贴纸颜色索引：0=U白 1=D黄 2=F绿 3=B蓝 4=R红 5=L橙

## 三、三阶层先法求解器（solve3）

### 3.1 总体结构

```js
function solve3(orig) {
  var cu = clone(orig), alg = [];
  function P(token) { alg.push(token); parseApply(cu, token, 3); }
  // 读取中心颜色（3×3 中心不动）
  var cc = {}; FACES.forEach(f => cc[f] = centerColor(cu, f));
  var W = cc.D; // 白 = D面中心色

  // 阶段 1~7（见下文）
  return alg.join(' ');
}
```

### 3.2 阶段 1：白十字（白花法）

目标：四条白棱归位到 D 层正确位置。

方法分两步：
1. **白花**：把每条白棱弄到 U 层、白朝上（不关心侧色位置）
2. **插入**：U 转到侧色对齐目标面中心，然后目标面 180°

白花阶段（每条棱）：
- 如果已在 U 层白朝上 → 进入下一条
- 如果在 D 层 → 侧色所在面 180° 提到 U
- 如果在 U 层白朝侧 → 转 U 让白贴纸到目标面 f 的正上方，然后 f 单转（掉到中层，下轮处理）
- 如果在中层（白在 wf 面、侧在 of 面）：
  - 尝试转 of（cw 和 ccw），检查白是否到 U 层
  - 尝试转 wf（cw 和 ccw），检查白是否到 U 层
  - 四次尝试必有一次成功（±90° 必然把侧面法线映射到 ±U）
  - 成功后保持（不回退）

关键注意：中层提起到 U 时，白可能朝上也可能朝侧。两种都接受。
- 白朝上 → 直接进入 U-align + 插入
- 白朝侧 → U 转到目标面上方，单转 f 进中层，再走一遍

**不能干扰已放好的棱的保证**：我们的棱在中层/中层位置，已放好的棱在 D 层自己的槽。
转一个面（比如 R）只会把 R 自己 D 槽的棱（未放好的）踢到中层，不会碰其他已放好的棱。
（因为如果 R 的棱已放好，它在 R 的 D 槽，不在中层——我们的棱在中层，R 的棱必然不在 R 槽 = 未放好）

### 3.3 阶段 2：白角（D 层四角）

目标：四个白角归位到 D 层正确位置、正确朝向。

方法（经典性感触发器法）：
- 四个槽位及对应触发器（已验证只干扰自己槽 + U 层）：
  - DFR: `(R U R' U')×k`
  - DFL: `(F U F' U')×k` —— 等价于 `F U F' U'`（已验证只动 DFL 自身）
  - DBL: `(L U L' U')×k`
  - DRB: `(B U B' U')×k`
- 每个角的流程：
  1. 找到角（3 个贴纸）
  2. 如果已就位且朝向正确 → 下一个
  3. 如果在 D 层但位置/朝向不对 → 用它所在槽的触发器打一次（弹到 U 层）
  4. 在 U 层 → 转 U 直到角在目标槽正上方（两个侧色贴纸分别面向 slot.f 和 slot.r）
  5. 重复目标槽的触发器（≤6 次）直到就位

**不能干扰已放好角的保证**（以 DFR 触发器为例）：
- R 转 DFR→URF（弹出），同时 DRB→DFR（暂移）
- U 转 U 层（DRB 的贴纸暂时在 DFR 位置，y=-2 不受 U 影响）
- R' 把暂移到 DFR 的 DRB 角转回 DRB ✓ 恢复
- U' 不碰 D 层
- 结论：R U R' U' 只改变 DFR 槽的内容 + U 层，DRB/DBL/DLF 均恢复 ✓

### 3.4 阶段 3：中层棱

目标：四条不含黄色的棱归位到中层。

方法：
- 对每条中层棱（颜色 = 两个相邻面的中心色）：
  1. 如果已就位 → 下一个
  2. 如果卡在中层（位置或朝向不对）→ 对它所在槽做一次插入操作（用顶层随便什么棱顶出来）
  3. 在 U 层 → 转 U 让侧面贴纸对齐同色中心 → 判断另一个色在右还是在左 → 用对应插入公式

插入公式（以 F-R 槽为例）：
- 右插（棱从 U 层进 FR）：`U R U' R' U' F' U F`
- 左插（棱从 U 层进 FL）：`U' L' U L U F U' F'`

其他槽通过 y 旋转映射：保持 U/D 不变，F→R→B→L→F 循环替换公式中的面字母。

y 旋转映射表（把「以 F 为前方」的公式映射到「以 X 为前方」）：
```
map.F = X
map.R = right[X]   // right = {F:'R', R:'B', B:'L', L:'F'}
map.L = left[X]    // left  = {F:'L', L:'B', B:'R', R:'F'}
map.B = opp[X]     // opp   = {F:'B', B:'F', R:'L', L:'R'}
map.U = 'U'
map.D = 'D'
```

### 3.5 阶段 4：黄十字

目标：U 面四条棱的贴纸变为黄色（不管位置）。

算法：`F R U R' U' F'`

循环逻辑：
- 0 个黄 → 直接跑一次 → 变 L 或一字
- L 形（相邻 2 个黄）→ 转 U 到「UB + UL」位置 → 跑一次
- 一字（相对 2 个黄）→ 转 U 到「UL + UR」位置 → 跑一次
- 十字（4 个黄）→ 完成

最多循环 3 次。

### 3.6 阶段 5：黄棱换位

目标：U 层四条棱的侧面颜色与对应面中心色一致。

算法：`R U R' U R U2 R'`（换三棱，保持 B 位不变——需实测确认保持位）

循环逻辑：
- 4 个全对 → 完成
- 恰好 1 个对 → 转 U 把对的棱放到固定位置（需实测确认算法保持哪个位置），跑算法
- 0 个对 → 先跑一次 → 变成 1 个对 → 进入上一步

最多循环 3 次 + 最终 U 对齐。

### 3.7 阶段 6：黄角换位

目标：U 层四个角的侧面颜色与对应面中心色一致（不管朝向）。

算法：`U R U' L' U R' U' L`（三角换，需实测确认保持哪个位置）

循环逻辑：
- 4 个全对 → 完成
- 恰好 1 个对 → 转 U 把对的角放到算法保持的位置 → 跑算法
- 0 个对 → 先跑一次 → 变成 1 个对

最多循环 3 次。

### 3.8 阶段 7：黄角翻色

目标：U 层四个角的黄色贴纸全部朝上。

算法：`(R' D' R D)×2或×4` 对 URF 位置的角重复直到黄朝上，然后 U 转下一个角。

循环逻辑：
```
for guard ≤ 40:
  找一个黄不朝上的 U 层角
  如果没有 → break
  转 U 把这个角转到 URF 位置
  重复 (R' D' R D) 直到 URF 角的黄色朝上（≤4 次）
  转 U（进入下一个角）
最后: 转 U 直到 U 层侧色全部对齐（≤3 次）
```

关键性质：R' D' R D 会暂时打乱 D 层和中层，但所有角都翻完之后自动恢复（经典性质）。

## 四、四阶降阶法求解器（solve4）

### 4.1 总体结构

```
阶段 A: 还原六个中心（每面 2×2 同色）
阶段 B: 拼合 12 条棱（每条棱的两个 wing 合并到同一 domino 位置）
阶段 C: 把 4×4 当作 3×3 用宽转层先法还原
阶段 D: 修正奇偶（OLL parity / PLL parity）
```

### 4.2 阶段 A：还原中心

目标颜色：从角块读取（角块永远不分裂，角块的贴色就是该面的目标中心色）。

方法：逐面还原（顺序 U, D, 然后四个侧面）。

对每个目标面 T：
1. 找一个颜色正确但不在 T 面中心区域的贴纸
2. 通过面转 + 内层转把它搬到 T 面中心区域
3. 重复直到 T 面中心区域 4 格全为此色

关键：转面时不能破坏已还原的面。
- 面 T 自身旋转永远安全（中心在面内循环，不离开面）
- 内层切片会从相邻 4 个面各拿 2 个中心贴纸 → 会破坏已还原的面
- 解决：还原顺序 + 仅用未还原面的转 + 必要时「先转走还原面的贴纸再切片再转回」（三步保复合操作）

**具体实现建议**：用宏查表而不是手写 case。宏 = 一小段 move 序列，效果是把一个中心贴纸从位置 P 搬到位置 Q，同时只扰动未还原的面。宏可以用穷举搜索自动发现（对指定 start/end 跑 BFS，限制不能破坏已还原面）。

BFS 搜索空间：4×4 中心块 24 个，状态 = 哪些面已还原 + 当前目标贴纸位置。限制：搜索深度 ≤ 6，分支 12（6 外层 + 6 内层）。深度 6 = 12^6 = 3M 可能太慢。可以用 IDDFS + 剪枝（不能破坏已还原面 → 大幅剪枝）。

**更简单的方案**：手动写 case 表。4×4 中心还原的经典方法：
- 第一面（U）：用 L/R/F/B 的内层切片把目标色搬到 U，U 转对齐
- 第二面（D，对面）：同上但注意保护 U → 用 D 面自己的旋转 + 相邻面的内层切片
- 四个侧面：最后一个面用特殊处理

实测迭代是关键。建议先写一个不完美的版本 → 测试 → 看哪些 case 失败 → 针对性补。

### 4.3 阶段 B：拼棱

目标：12 条棱，每条棱的两个 wing（半个棱块）颜色一致且在同一 domino 位置。

方法（经典拼棱法）：
- 用 U 层作为工作区
- 对每条未拼合的棱：
  1. 找到同色的两个 wing
  2. 一个放到 UF 上半（或下半），另一个通过 U 转对齐
  3. 用拼棱公式：`Rw U' Rw'`（或其他变体）把两个 wing 合并
  4. 合并后的棱放到「已完成区」
  5. 重复

拼棱公式 `Rw U' Rw'` 的效果（已验证中心安全）：
- Rw 把 R 面中心旋转（R 中心均匀 → 安全）
- Rw 把 U/D/B 的右内列中心贴纸拿到中间层，但 Rw' 会转回来（U 转之后 Rw' 拿的是不同的贴纸）
- 需实测确认：`Rw U' Rw'` 执行后，中心是否全部保持均匀

关键：拼棱操作不能破坏已还原的中心。`Rw U' Rw'` 中 Rw 移动中心贴纸，但 Rw' 恢复（因为 U 只转 U 面，U 面中心贴纸不会离开 U 面 → Rw 和 Rw' 对非 R 面的中心效果互逆 → 中心安全）✓

**具体实现**：拼棱需要逐 wing 处理，用实测迭代。建议：
1. 先写一个「打印当前所有棱 wing 位置和颜色」的调试函数
2. 手动构造拼棱序列 → 测试 → 调整
3. 最终自动化

### 4.4 阶段 C：宽转层先法

中心 + 棱拼好后，4×4 等价于一个 3×3：
- 每个 2×2 中心块 = 3×3 的一个中心
- 每条拼合棱 = 3×3 的一条棱
- 角块 = 3×3 的角块

此时只需用宽转（Uw Dw Lw Rw Fw Bw）跑一遍三阶层先法。

实现：把 solve3 改造为接受「逻辑 3×3 视图」——把 4×4 的坐标映射到 3×3 的坐标：
```
4×4 坐标 → 3×3 逻辑坐标
-3, -1 → -2 (左/外)
 1,  3 →  2 (右/内)
```
即 `logical = coord > 0 ? 2 : -2`（中间坐标没有对应，因为中心/棱已合并）。

或者：写一个 `solve3Wide(cu)` 直接在 4×4 状态上运行层先法逻辑，但所有 faceTurn 换成 wideTurn，所有贴纸读取用 4×4 的坐标映射到 3×3 网格。

### 4.5 阶段 D：奇偶修正

宽转层先法完成后可能有两种奇偶：

**OLL parity**（一条棱翻色）：
标准公式：`Rw U2 x Rw U2 Rw U2 Rw' U2 Lw U2 Rw' U2 Rw U2 Rw'`
其中 x 是整体旋转 = `Rw Lw'`（4×4 上）。
因此可以改写为纯宽转：`Rw U2 Rw Lw' Rw U2 Rw U2 Rw' U2 Lw U2 Rw' U2 Rw U2 Rw'`
需实测验证。

**PLL parity**（两条棱交换）：
标准公式：`Rw2 U2 Rw2 U2 Rw2`（简写版）
需实测验证。

**检测方法**：
- 宽转层先完成后，检查是否 solved
- 如果不是：统计 U 层棱的不匹配数
  - 奇数 → OLL parity
  - 两个棱互换 → PLL parity
- 修正后如果还不完全 solved → 再跑一次宽转层先的最后几步（或全文再跑一次）

### 4.6 测试方法

```js

  var cu = mkCube(4);
```

## 五、渲染

### 5.1 等距投影

```js
function proj(p, yaw, pitch) {
  var cy = cos(yaw), sy = sin(yaw);
  var x1 = p[0]*cy + p[2]*sy;
  var z1 = -p[0]*sy + p[2]*cy;
  var cp = cos(pitch), sp = sin(pitch);
  var y1 = p[1]*cp - z1*sp;
  var z2 = p[1]*sp + z1*cp;
  return { x: x1, y: y1, z: z2 };
}
```

### 5.2 贴纸渲染

对每个可见贴纸：
1. 计算面中心：`fc = worldPos + worldNormal * 1.0`
2. 计算两个切向量（垂直于 worldNormal）
3. 四角 = fc ± t1 * 0.42 ± t2 * 0.42
4. 投影四角到 2D
5. 深度 = 四角 z 平均
6. 所有四边形按深度排序，从远到近绘制
