帮助.chm — 船只悠悠的小站使用手册
❓ 这台"电脑"上所有能玩的东西, 全都在这一页里。大部分彩蛋没有提示, 但这一页是官方外挂。
⌨ 快捷键与暗号
  • ~ / ` — 呼出终端 (点主窗口标题栏文字也一样)
  • ↑↑↓↓←→←→BA — Konami 彩虹模式(再输一遍收起来)
  • 连按 WASD / 方向键 — 风浪来袭, 全船摇晃
  • 终端里输入 help, 能看到它的全部命令; ↑↓ 翻历史
🖱 处处可点
  • 开始菜单翻新了: 系统与设备 / 网站设置(屏保时长·夜航·音效·开机动画) / 游客信息 — 你是第几次上船, 它记得
  • 左下角三块小面板: 甲板音乐(五首 VOCALOID 已上架, 像素频谱跟着唱) + 船长状态(课表驱动的状态灯, 地点/事情/心情实时更新) + 灵动岛(实时报你此刻在干嘛, 顺便记你上船几分钟)
  • 站名 / 副标题 / 运行天数 / 各板块标题 / 便利贴 / 页脚时钟 — 挨个点过去, 全都有回应
  • 相册: 九本板块相册(已开张七本), 点封面选中, 双击封面或点「翻开相册」在独立窗口里看全部图片; 图片点开放大, ← → 切换, Esc 关闭
  • 右下角小船: 点一下 +1 海里 — 10 红帆 · 30 海鸥 · 60 金帆 · 100 夜灯
🗂 任务栏应用一览
  • C:\ 终端 — 仿真命令行, help 看命令; 试试 ship / tree / sudo / start help.chm
  • ? 帮助.chm — 就是你现在看的这个(翻开前会先过一道剧透确认, 你已经过了)
  • = 计算器 — 支持键盘输入, ÷0 会被严肃拒绝
  • 雷 扫雷.EXE — 首点必安全; 右键或长按插旗, 点笑脸再来一局
  • 日 日记.EXE — 按日期快速翻船舱日记, 和主页日历联动
  • e 小站浏览器 — 只能访问船际网络认证站点; 乱输网址有老式 404, 输 deepsea 有惊喜
  • 漏 沙漏.EXE — 像素沙漏倒计时, 沙粒真实掉落; 1/3/5/10/25 分钟, 写作业开 25 分钟正好
  • 画 画板.EXE — 24×24 像素画板: 画笔/油漆桶/橡皮/撤销, 画完点"下载 PNG"打包带走
  • 阳 太阳系.EXE — 真实比例+真实周期: 左侧星球列表点谁去谁, 拖动平移, 滚轮缩放, 点行星看资料; 找不到地球? 先缩小看全家福, 再凑近
  • 倒 倒数日.EXE — 内置节日倒数(含农历) + 自定义事件可写详细说明, 谁的日子近谁排前面
🌙 这台电脑也会累
  • 19:00~6:00 自动进入夜航模式 (托盘点灯可手动切换, 全站配色跟随)
  • 闲置 两分钟, 屏保自己开演: 星空 + 小船 + 像素时钟, 动一下就回来
  • 开始菜单 → 关机: CRT 坍缩收场, "电源"键重新开机, 还带 BIOS 自检
  • 同时开 4 个应用会蓝屏 — 640K 内存的极限; 按任意键退出, 代价是全部窗口关闭
🌊 还有些温柔的角落
  • 第一次登船会收到一封欢迎信; 想重读的话, 开始菜单 → 游客信息里能再要一份
  • 船舱日记的日历上, 红点标过的日子船都出过海
  • 留言板可以捞漂流瓶 — 每一条都是真的旅客留言
  • 便利贴的宜忌是编的, 但"宜: 写代码"每天都灵
